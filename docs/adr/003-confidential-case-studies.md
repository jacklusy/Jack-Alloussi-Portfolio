# ADR 003: Case studies for confidential professional work

## Status

Accepted

## Context

Most production work sits in private client repositories and cannot be shown as code.

## Decision

Use prose case studies that describe system type, architecture, decisions, tradeoffs, and outcomes without naming clients or publishing proprietary artefacts.

## Consequences

- Highest-value pages are writing-heavy.
- Personal public repos still needed for code evidence once available.
