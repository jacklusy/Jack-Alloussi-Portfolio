# ADR 002: Status Rail as the signature element

## Status

Accepted

## Context

Recruiters filter hard on work authorisation. A generic hero with stats or a photographic splash does not answer that filter in the first seconds.

## Decision

Lead with a monospace Status Rail encoding availability, location, EU Blue Card eligibility, and graduation date. It is the visual signature and a functional answer.

## Consequences

- Branding is unusual for portfolios (intentional).
- Visa messaging is duplicated in contact without relying on users discovering it.
